# PROJECT BRIEF — Işıktepe Eğitim Gönüllüleri Derneği Website

## 1. Organization Overview

**Full Name:** Işıktepe Eğitim Gönüllüleri Derneği  
**Focus:** Educational volunteering, mentorship, and alumni networking — starting from the town of Işıktepe and expanding across Turkey.

### Mission (Misyon)

The organization pursues three pillars:

1. **Mentorluk ve Kariyer Koçluğu** — University students and alumni guide younger students with experience, inspiration, and career coaching to prepare them for life.
2. **Sinerji ve Ağ Oluşturma** — Bringing alumni together by field of study to encourage knowledge sharing and professional solidarity, contributing to a secular, science-based educational community.
3. **Birleştiricilik** — Building an inclusive community culture rooted in town belonging, respecting diverse views and lifestyles, free from discrimination — learning and growing together.

### Vision (Vizyon)

Starting from Işıktepe and spreading to all corners of Turkey: creating a non-divisive, strong, and sustainable educational volunteering model that maximizes the region's youth potential and becomes an exemplary mentorship and solidarity community.

> *"Işıktepe'den yükselen umutla, eğitimin gücünü her çocuğun, her gencin ve her bireyin hayatına taşımak!"*

---

## 3. Project Goals

1. **Awareness** — Introduce the organization, its mission, and vision to all target audiences.
2. **Volunteer Recruitment** — Make it easy and compelling for potential mentors and volunteers to sign up.
3. **Community Building** — Showcase the alumni network and inspire participation.
4. **Credibility** — Present a professional, trustworthy online presence for the organization.
5. **Information Hub** — Centralize events, announcements, and contact information.

---

## 4. Core Themes

- Mentorship and career coaching for students
- Alumni networking and knowledge sharing
- Inclusion, solidarity and respect for different views and lifestyles
- Equal opportunity in education
- A sustainable educational volunteering model starting from Işıktepe

## 5. Technical Decisions

| Decision | Choice |
|---|---|
| **Architecture** | Single-page scrolling site (SPA-style) |
| **Technology** | Pure static HTML / CSS / JavaScript — no frameworks, no build tools |
| **Language** | Turkish only (MVP) |
| **Hosting** | GitHub Pages (custom domain planned for the future) |
| **Forms** | Configurable external form links (placeholder URLs for MVP) |
| **Color Mode** | Light mode only for MVP |
| **Accessibility** | WCAG AA compliance |
| **Backend** | None — fully static MVP |

---

## 6. Design Decisions

| Decision | Choice |
|---|---|
| **Hero Section** | Animated gradient (turquoise/burgundy) with bold text and floating subtle star particles |
| **Navigation** | Sticky/fixed header, shrinks on scroll, hamburger on mobile |
| **Typography** | Inter (Google Fonts) |
| **Colors** | Turquoise (primary), burgundy-purple (secondary), subtle yellow star accents |
| **Animations** | Minimal — hover effects on buttons and cards only |
| **CTAs** | Floating "Gönüllü Ol" button + section CTAs throughout the page |
| **Photos** | Placeholder images with descriptive alt text (real photos to be provided before launch) |
| **Logo** | JPG file with white borders — CSS clipping/masking to handle borders |
| **Donation** | Bank account / IBAN details displayed on the page |
